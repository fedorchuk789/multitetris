# Мультитетрис

Браузерная 3D-игра: тетрис не на одной стене, а на трёх — левой, передней и правой. Игрок стоит в центре комнаты, поле загнуто буквой «П», и фигуры переезжают через углы.

- Каждая стена сжигает свои ряды; один и тот же ряд на всех трёх стенах сразу — «Кольцо» и большой бонус.
- 5 стилей стен: Неон, LEGO, Стекло, Дерево, Космос — у каждого своя музыка.
- Управление с клавиатуры и на телефоне (кнопки и жесты).

Играть: откройте `index.html` в браузере (нужен интернет для Three.js).

**Клавиши:** ← → двигать · ↑/X повернуть · Z повернуть обратно · ↓ ускорить · Пробел бросить · C запас · V камера · T стены · M/N музыка/звуки · P пауза.
